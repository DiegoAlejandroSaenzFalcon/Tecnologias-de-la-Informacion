## Cómo usar esta guía

1. Lee la visión general y el módulo correspondiente.
2. Estudia la teoría y revisa los diagramas.
3. Practica con los recursos gratuitos indicados.
4. Completa el checklist de dominio antes de avanzar.
5. Verifica tus resultados con fuentes oficiales cuando el tema dependa de una plataforma o producto concreto.

## Enfoque

La guía cubre fundamentos de hardware, troubleshooting, redes TCP/IP, sistemas operativos, administración, seguridad, automatización y preparación práctica. Las referencias a productos, cursos o certificaciones de terceros se presentan como referencias educativas y no como afiliación o respaldo.

## Recursos gratuitos

Entre los recursos utilizados como apoyo se encuentran Cisco Networking Academy, Wireshark, Linux Journey, TryHackMe, OverTheWire, picoCTF, Microsoft Learn, VirtualBox y GitHub Skills. Consulta siempre las condiciones actuales de cada plataforma.
